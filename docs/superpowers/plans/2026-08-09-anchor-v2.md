# ANCHOR-V2 Implementation Plan (gcd-free RNS/CRT anchor + growing dyadic shadow)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the gcd-bound exact-rational anchor with a bit-identical gcd-free anchor: RNS residues for ring arithmetic + a growing arbitrary-precision dyadic interval shadow for branch decisions, with CRT/rational-reconstruction fallback, per PRE-REG ANCHOR-V2 (relays 2026-08-09-5/-6).

**Architecture:** A new scalar `rx` = {residue vector mod pinned 61-bit primes, dyadic interval shadow at ~50+20·N bits}. Ring ops (+,−,×, exact ÷, 2^n shifts) act on both halves; branch sites (compares, floors, zero-tests) are decided by the shadow when it can, by residues for zero-tests, and by CRT reconstruction (counted per class) when neither decides. Instantiates the existing templated `core::birth_impl<Op,Acc,Round>` unchanged.

**Tech Stack:** C++20 header-only (repo idiom), `ax::bigint`/`ax::rational`, `__int128` modular arithmetic, gtest suite in `tests/`, CMake.

## Global Constraints (frozen pins — copy of the pre-reg)

- Pin 1: zero-tests (`==`) route to residues, NEVER to the interval.
- Pin 2: exact-boundary fallbacks are cached per site-value (repeat straddles at structural sites reconstruct once).
- Pin 3: shadow precision GROWS with the prefix: `prec_bits = 50 + 20·step` (prevents the measured d64 step-3 collapse at 15–20 bits/step).
- Pin 4: per-class fallback counters {eq-zero, floor-exact, floor-near, cmp} + reconstruction count are registered observables.
- Bars: **P-DIGEST-EQUAL** (anchor2 digest == exact-anchor digest on overlap cells, incl. one SCHED boundary and one forced fallback) and **P-HORIZON** (12-step d64 anchor ≤ 4 h).
- Tier-1 gate FIRST: freeze the `exr::guard()` mutable static cache.
- Everything runs Mac CPU; nothing launches on the 3080.
- Default builds must stay unchanged (existing 508+ tests stay green).

### Task 4: `rx` scalar + `Exact2` policy + counters

**Files:** Create `include/ax/nn/exact_anchor2.hpp`; Test `tests/nn/exact_anchor2_test.cpp` (first half).

**Interfaces (Produces):**

```cpp
namespace ax::nn::ib::anchor2 {
struct fb_counters {           // pin 4 — registered observable
  long eq_zero = 0, floor_exact = 0, floor_near = 0, cmp = 0;
  long recon = 0, cache_hit = 0;
};
struct rx {
  std::vector<std::uint64_t> res;   // residues (ctx primes)
  std::vector<std::uint8_t>  okm;   // pole mask
  ax::dyi sh;                       // certified shadow
  static inline ax::rns_ctx ctx;         // set by init()
  static inline fb_counters fb;
  static inline std::unordered_map<std::uint64_t, ax::bigint> site_cache; // pin 2
  static void init(int nprimes, int prec_bits);  // freezes ctx, dyi::prec
  ax::rational reconstruct() const;   // throws "anchor2: modulus exhausted" if !ok
  // ctors int/long/long long; + - * unary- += -= *= << >> ;
  // == via residues (pin 1); <=> via shadow, cmp-fallback reconstructs a-b;
  // explicit operator long long/long (post-floor point integers only)
};
struct Exact2 { static rx div(a,d); div_trunc = div; to_grain; from_grain; };
using anchor2_birth = core::birth_impl<rx, rx, Exact2>;
}
```

Key semantics to implement exactly:

- `==` (pin 1): `d = a - b`; true iff every clean residue of `d` is zero AND `d.sh.contains_zero()`; require ≥ 3 clean primes else reconstruct. Count `fb.eq_zero` only when a reconstruction was needed (pole-starved), not on the native path.
- `<=>`: if `a.sh` and `b.sh` disjoint → decide from endpoints. Else `fb.cmp++`, `r = (a-b).reconstruct()`, decide by `r` sign, and REFRESH: caller value unknown, so refresh the difference only (decision is what matters; state tightening happens at floors).
- `Exact2::to_grain(x, g)`: `s = x >> g`; `auto [fl,fh] = s.sh.floor_pair()`; if `fl == fh` → result = exact integer `fl` (residues set from `fl`, shadow point — this is the seam re-exactification that keeps widths bounded). Else: site-cache lookup keyed on `hash(s.res)` (64-bit FNV over residue words); hit → `fb.cache_hit++`, use cached floor. Miss → `r = s.reconstruct()`, `fb.recon++`, exact floor of `r` (divmod, negative-aware); classify `fb.floor_exact++` if `r` integral else `fb.floor_near++`; insert cache.
- `Exact2::div`: shadow via `dyi::div`; residues `x_i · invm(d_i)`; if `d_i == 0` (pole, but d ≠ 0 globally — check via `==` semantics first and throw on true zero divisor) mark result residue poisoned in `okm`.
- `operator long long`: requires `sh.is_point()` with integral exponent (holds post-to_grain, the only conversion sites in the core, matching `exr`); extract via `bigint::to_string` + `stoll` like `exr` does.
- `<< n` / `>> n`: residues × `powm(2,n,p)` / × `invm(powm(2,n,p))`; shadow exponent shift. Exact, no rounding.
