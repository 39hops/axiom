# Number-theory chains (relay -9, priority 1)

New-domain engine per llmopt relay 2026-07-27 -9: multi-step exact-integer
derivations. Double payoff per the relay: CRT/modular is the RNS exact-GEMM
machinery, continued fractions are the best-rational snap — this engine is
exact-stack infrastructure, not just row supply.

## Families (all 3 levels, operand digits 2 / 4 / 8)

| family | derivation | closing row |
|---|---|---|
| nt_gcd | Euclid divisions (mul/sub/gcdstep per step) | gcdend: gcd(g, 0) -> g |
| nt_bezout | gcd chain + s/t coefficient recurrences | bezout: a*s + b*t -> g |
| nt_modinv | bezout on (a, m), coprime by construction | inv + invcheck (Mod(a*inv, m) -> 1) |
| nt_crt | iterative lift over 2–3 coprime moduli, inverse sub-chain inline | crtcheck per congruence |
| nt_modexp | square-and-multiply (mod/sq/mulstep) | modexp: Mod(b**e, m) -> result |
| nt_cf | Euclid quotients + convergent recurrences h/k | det: h*k' - h'*k -> ±1 |

## Oracle (free, exact)

Every row is certified by `nt_eval` — an exact bigint parse-and-evaluate of
BOTH emitted strings (the oracle runs on the bytes, not the construction),
then the whole problem is cross-checked against the independent `core/nt`
implementations (`gcd`, `ext_gcd`, `modinv`, `crt`, `modpow`). Failing
problems are written `UNDECIDED` with an honest error, never dropped.

## Serialization spec / atom list (VOCAB_EXTRA contract)

The 19M ODE probe died VOID-BY-VOCAB; rows ship their atoms:

- characters: digits `0-9`, `+ - * ( ) ,` and space
- names: `gcd(a, b)` (nonnegative), `Mod(a, m)` (least nonnegative residue, m > 0)
- operator: `**` (nonnegative literal exponent, closing modexp row only)
- negative literals inside binary spellings are always parenthesized

The emitter writes a sidecar `<out>.config.json` carrying the atom list,
family roster, and problem/row/certified counts.

## Fences honored

- rows stream incrementally (per-problem flush — killed workers keep rows)
- string seeds (`nt_<family>-<level>-<seed>`), reseed offset 1'000'003 on
  degenerate draws (same collision-guard discipline as physchain)
- deterministic by seed (test-gated)
- oracle is exact integer arithmetic — no timebox needed, no censoring path
- determinability: cur determines nxt on every row kind (quotients are
  floor-division of the two literals in cur; inverse rows follow their own
  emitted bezout sub-chain)
